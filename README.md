# 職場霸凌調查遊戲

把台灣法院公開的職場霸凌相關判決去識別化，改編成互動式調查小遊戲。玩家扮演公司內部的職場霸凌調查小組，約談當事人、調閱證據、找出說法矛盾，並在程序關卡中做出抉擇，最後寫下調查結論，再對照法院實際的判決見解。

對象是沒有參與過職場霸凌調查的一般民眾，目標是讓人體驗「兩造都要聽、證據說話」，也認識 2026 年 7 月 1 日施行的《職場霸凌防治措施準則》。

## 怎麼玩

用瀏覽器直接打開 `game/case01.html` 即可，不需要安裝或後端。手機、桌機都可以玩，支援深色模式。預計 20 分鐘左右。

## 檔案結構

```
game/
  case01.html            Case 01 遊戲（單一 HTML 檔）
docs/
  提示詞.md               製作新案件時可重複使用的提示詞（五階段流程）
  case01/
    案件拆解.md           去識別化規則、人物、證據、證詞、矛盾點、程序關卡、法院認定
    遊戲機制設計.md       點數、矛盾標記、程序評分、三段式結論、結局與成就
```

## 製作原則

- 只使用公開判決。依著作權法第 9 條，判決不受著作權保護。
- 人物、機構、產業、地點、時間全部改寫；判決記載的事實與法院見解不竄改。
- 為了遊戲回推的內部調查情境，在素材中標註「改編」，不改變判決的核心事實與結論方向。
- 程序關卡依《職場霸凌防治措施準則》設計；判決沒有評價的程序部分，遊戲中會註明。

## 聲明

本遊戲改編自台灣法院公開判決，人物與機構均為虛構，內容僅供教育與體驗，不構成法律意見。判決可能仍在上訴中，最新狀態請以司法院裁判書系統為準。
