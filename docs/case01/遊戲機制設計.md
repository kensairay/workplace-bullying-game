# Case 01 遊戲機制與流程設計（Step 3）

> 版本：v1（2026-09-30 發布）
> 與 Step 3 原稿的差異：程序關卡改為「選完立即回饋」，結局頁再完整回顧一次。

## 一、整體流程與時間

| 階段 | 內容 | 預估時間 |
|---|---|---|
| 開場 | 內容提醒、聲明、玩家身分（新制調查小組） | 1–2 分 |
| 閱卷（D 日） | E1 申訴信與 16 項事件、E2 診斷證明、E11 座位方案、E13 刑事告訴資訊、準則小卡 | 2–3 分 |
| P1 → P3 | 受理當天：保護措施、組成調查小組 | 2 分 |
| P4 | 第一次約談前決定訪談方式 | 1 分 |
| 調查階段 | 12 點調查點數；中途觸發 P2、P5 | 8–12 分 |
| 三段式結論 | 成立與否、關鍵證據、處置建議 | 2–3 分 |
| 結局揭曉 | 評分、稱號、法院見解、下一案預告 | 3–4 分 |
| **合計** | | **約 19–27 分鐘** |

## 二、機制 1：有限調查點數（12 點）

| 行動 | 成本 |
|---|---|
| 約談初次陳述（林以晴、韓靜宜、許主任、杜經理、葉主任） | 每人 1 點 |
| 追問（共 5 題，部分需要先標記矛盾才解鎖） | 每題 1 點 |
| 調閱證據 | E3、E4、E12 各 2 點；E5–E10 各 1 點 |
| 免費資料 | E1、E2、E11、E13，以及「準則小卡」 |

**全部行動合計 23 點**，12 點大約只能查一半，玩家必須取捨。

**滿分路線**（12 點）：
- 調閱 E9、E10（2 點）→ 完成 C4（須在花掉第 4 點、觸發 P2 之前）
- 約談林以晴、追問疫苗、調閱 E3（4 點）→ 完成 C1
- 調閱 E6（1 點）→ 完成 C2
- 約談韓靜宜、調閱 E7（2 點）→ 完成 C3
- E11 對照準則小卡（0 點）→ 完成 C5
- 調閱 E4（2 點）→ 取得關鍵證據
- 追問韓靜宜「會議錄音」（1 點）→ 解鎖「兩造都聽了」成就

**觸發事件**：
- 花掉第 4 點時觸發 **P2**
- 花掉第 8 點時觸發 **P5**

## 三、機制 2：矛盾標記

- 從卷宗勾選兩份資料，按「標記矛盾」。
- 配對正確：蓋章動畫、解鎖追問或新選項、事實認定 +12 分。
- 配對錯誤：事實認定 −4 分（最低 0），並給提示。
- 矛盾點 C1–C5，內容見「案件拆解.md」。

---

## 四、機制 3：程序正當性（v1 改為即時回饋）

- P1–P5 各 20 分；部分正確 10 分。
- **選完立即回饋**：顯示「處理得當／部分正確／不妥」印章、理由、較好的做法、準則條文、原案公司的做法。
- 狀態列的五個印章同步變色。
- **連動規則**：整場未約談韓靜宜，P4 以 0 分計（準則第16條、第22條第4項第2款）。
- **P2 特殊設計**：須先完成 C4，才會出現「轉介外部心理諮商」選項；沒找到時，回饋會告知錯過了什麼。

## 五、機制 4：三段式結論（100 分）

**(a) 霸凌是否成立：40 分**
不成立 40／部分成立 15／成立 0

**(b) 關鍵證據（最多 5 項）：30 分**
- E3、E4、E5、E6 各 +7.5
- E2、E13 各 −5
- 範圍 0–30

**(c) 處置建議（可複選）：30 分**

| 選項 | 得分 |
|---|---|
| 轉介外部心理諮商 | +10 |
| 工作場所區隔與分工調整 | +10 |
| 修訂預防規範：當事人是醫護人員時改由外部輔導 | +10 |
| 懲處被申訴人 | −10 |
| 調離或資遣申訴人 | −15 |
| 向全廠公告調查結果 | −10 |

範圍 0–30。

## 六、機制 5：結局揭曉

**評分**（總分 300）：
- 事實認定：矛盾 5 × 12 = 60，扣除錯誤標記；關鍵證據 E3、E4、E6、E9、E10 各 8 分，共 40
- 程序正當：P1–P5
- 與法院一致：上節

**稱號**：0–149 菜鳥調查員｜150–219 見習調查委員｜220–269 可靠的調查委員｜270–300 真相追尋者

**結局頁順序**：
1. 你 vs 法院：霸凌不成立 → 蓋章「但公司敗訴」
2. 程序回顧 P1–P5（P3–P5 註明判決未評價、依新準則設計）
3. 調查結束後才出現的資料：不起訴、精神鑑定、勞動檢查、前同事私訊
4. 白話解說法院見解
5. 給上班族的三個提醒
6. 原判決案號與狀態聲明
7. Case 02 預告「權限消失的帳務員」＋重玩按鈕
