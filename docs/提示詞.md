# 專案目標
把台灣公開的職場霸凌相關判決去識別化後，改編成互動式調查遊戲。
玩家扮演「公司內部職場霸凌調查小組」，從證據與證詞中形成判斷，做出調查結論，最後對照法院實際見解。
目標是「引人入勝、讓玩家想接著玩下一案」，同時寓教於樂。

# 目標對象
一般民眾，沒有法律、人資或調查經驗。
- 所有法律概念都要用白話解釋，第一次出現的專有名詞要附簡短說明。
- 遊戲內閱讀量要控制：單段文字不超過手機一個畫面。

# 工作流程（每個階段結束都要停下來，等我確認才繼續）

## 階段 1：案件搜尋與篩選
- 只使用司法院裁判書系統等公開判決。
- 建議搜尋關鍵字：職場霸凌、民法第483條之1（雇主保護義務）、民法第184、188、195條、勞基法第14條第1項、職業安全衛生法第6條第2項第3款。
- 列出 3–5 件候選，每件說明：
  - 案號、審級、判決結果
  - 核心爭點
  - 有哪些證據類型
  - 適合遊戲化的理由（例如：有反轉、有程序瑕疵、證據互相矛盾）
- 優先挑選這幾類案件：
  - 事實記載充分
  - 證據多元
  - 公司調查結論與法院見解有落差
  - 涉及調查程序爭議
- 判決全文與要旨必須實際查閱，不可憑記憶描述。

## 階段 2：去識別化與案件拆解
### 去識別化規則
- 所有自然人、公司、單位名稱都改用虛構名稱。
- 產業改為同類型但不同的產業。
- 縣市、具體地址、日期、職稱、金額都要改寫或模糊化（例如改寫為「約半年間」）。
- 保留足以理解案情的時序與相對關係。
- 刪除可反查原案的獨特細節，例如特定事件名稱、罕見職稱、新聞報導過的特徵。
- 另外附一份「原案 ↔ 改編」對照表，只給我看，不放進遊戲。

### 案件拆解，產出以下素材
1. 案件概要：申訴人主張什麼、被申訴人是誰、申訴時間點
2. 人物卡（4–7 人）：身分、與當事人的關係、立場、可信度線索
3. 證據卡（8–15 張）：訊息紀錄、郵件、出勤紀錄、考績、醫療證明、會議紀錄等
   - 每張標註：證據類型、取得成本、證明力、關聯的爭點
4. 證詞：每位人物的初次陳述，以及被追問後的陳述
5. 矛盾點清單（3–6 組）：哪兩項內容互相矛盾，標出後解鎖什麼
6. 程序關卡（3–5 個）：例如迴避、保密、給予陳述意見、保全證據、暫時隔離措施
7. 關鍵爭點與法院認定：每個爭點法院怎麼判斷、依據為何，要附判決出處段落

### 忠實原則
- 法院認定的事實與見解不得竄改。
- 為了遊戲而「回推」的內部調查情境（例如公司調查時可能取得的證詞），要在素材中標註【改編】。
- 【改編】內容不得改變判決的核心事實或結論方向。

## 階段 3：遊戲機制與流程設計
以下五項機制全部採用：

1. 有限調查點數
   - 玩家有固定點數（建議 10–12 點）。
   - 約談、追問、調閱證據各有不同成本。
   - 點數不夠查完所有線索，逼玩家取捨。不同路線要能導向不同的資訊掌握度。
2. 矛盾標記
   - 玩家可以把兩項證詞或證據配對，標記為「矛盾」。
   - 配對正確：解鎖隱藏線索或追問選項。
   - 配對錯誤：小幅扣分，並給提示。
3. 程序正當性量表
   - 調查過程中穿插程序抉擇。
   - 選錯不會立刻失敗，而是累積影響，最後在結局揭曉後果（例如「調查結論因程序瑕疵被法院質疑」）。
4. 三段式結論
   - (a) 霸凌是否成立：成立／部分成立／不成立
   - (b) 勾選支持結論的關鍵證據（最多 5 項）
   - (c) 處置建議：懲處、調整職務、心理支持、改善制度等，可複選
5. 結局揭曉
   - 評分分三項，各 100 分：事實認定、程序正當、結論與法院一致度
   - 依總分給調查員稱號（例如：菜鳥調查員 → 可靠的調查委員 → 真相追尋者）
   - 結局順序：
     1. 「你的結論 vs 法院見解」並列對照
     2. 白話解說法官見解：這件事法院怎麼看、為什麼、對一般上班族的啟示
     3. 預告下一案，並提供「重玩挑戰更高分」的選項

- 請畫出完整遊戲流程圖：開場 → 閱卷 → 調查（約談／調閱／標記）→ 程序關卡 → 結論 → 揭曉。
- 預估遊玩時間 15–25 分鐘。

## 階段 4：製作原型
- 單一 HTML 檔，手機優先，同時相容桌機。
- 不依賴後端。遊戲狀態存在記憶體中。
- 介面風格：調查卷宗感（檔案夾、便條、印章），閱讀舒適，支援深色模式。
- 互動回饋要即時：解鎖動畫、點數變化、線索通知。
- 開場必須包含：
  - 內容提醒：本遊戲涉及職場霸凌情節
  - 聲明：改編自公開判決，人物與機構均為虛構，不構成法律意見
- 結局頁附上原判決案號，讓玩家能自行查閱。

# 語氣與倫理
- 敘事要有懸疑感和代入感，但不美化、不娛樂化霸凌行為。
- 描寫受害經驗要克制，不渲染創傷細節。
- 對申訴人與被申訴人都保持中立。遊戲要讓玩家體會「兩造都要聽、證據說話」。
- 使用繁體中文，採台灣用語。
